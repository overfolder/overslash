# ReFocus and Adapting to Corporate

After doing a demo for Reveni i came up with some clear gaps Overslash as a product needs

## Organizations and users need to be able to curate service tools, as executor does

Overslash provided service def is the baseline
Orgs/Users? can override things when publishing in their catalog, while still supporting upstream Overslash updates. allow whitelisting tools, must work with autodiscover too

## We must be able to share prefilled services in org, without sharing a full instance with connection

For when we want each user to establish his own OAuth
This might ideally we solve by the same primitive as before

## Improve autoonboarding

## Approvals must be bigger, maybe full screen, standalone or much bigger modal

Approvals are the core UI 90% of users will interact with, it doesnt make sense to make it a small modal

## Corporations might want to gatekeep MCP clients

Some corporations only want to approve specific AI providers, claude, chatgpt, ...
Can Overslash help here?

## SQL is big

Might be worth to consider supporting SQL, together with human understandable SQL
Basic data governance capabilties...
Consider postgresrest wrappers and other strats to turn SQL into HTTP again...
